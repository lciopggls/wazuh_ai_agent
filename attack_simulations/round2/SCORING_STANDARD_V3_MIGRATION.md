# 评分标准 v3.0 迁移说明

生效日期：2026-08-05
六维度名称同步日期：2026-08-25
当前唯一评分依据：[评分标准v3.0.md](评分标准v3.0.md)

## 1. 生效规则

从本说明生效起，所有尚未完成评分的新报告统一使用 v3.0。v3.0 保留 v2.0 的六个
维度、权重和总分，只把 MITRE ATT&CK 基础表达改为 `0 / 5 / 15` 三级判定。

- `0`：没有任何合格攻击时间线项目；
- `5`：至少一个项目完整表达“时间 + 有效 T 编号 + 对应行为”，但未覆盖全部攻击
  时间线项目；
- `15`：每一个攻击时间线项目均在同一项目内完整表达上述三项；
- MITRE ATT&CK 映射质量仍单独按 `0～15` 评分；
- 其他五个维度和 v2.0 的其余规则不变。

### 1.1 2026-08-25 六维度名称同步

当前正式名称统一为：初始事件识别准确性、关键证据检索与覆盖度、事件时间线准确性、攻击链重建与因果分析、MITRE ATT&CK 映射质量、未发生行为核验。此次同步不修改稳定结构化字段、权重、总分和计分规则；历史文件保留其生成时使用的旧名称，属于明确的版本记录，不视为迁移遗漏。

## 2. 场景与历史分数边界

- SIM-201～SIM-203 的 27 份报告、单次 evaluation、三次汇总、对照汇总和总汇总是
  已冻结的 v2.0 历史评分证据，不改写、不覆盖，也不冒充 v3.0 分数；
- SIM-204～SIM-206 的新报告统一采用 v3.0，当前均已完成评分；
- SIM-204 `baseline_agent_simple R1` 在标准切换前已经生成，但尚未评分，因此直接
  使用 v3.0，不先生成 v2.0 分数；
- 若以后需要把 SIM-201～SIM-203 改用 v3.0 比较，必须新建独立的 v3.0 评分文件和
  汇总，不得覆盖历史 v2.0 文件；
- v2.0 与 v3.0 分数不得在未明确标注口径的情况下直接合并、计算提升比例或平均值。

## 5. 防回退检查

新建或更新当前评分文件时必须同时满足：

1. 评分依据写为 `评分标准v3.0.md`；
2. MITRE 基础表达只取 `0 / 5 / 15`；
3. 每个攻击时间线项目按 v3.0 第 7.2 节逐项检查；
4. 不用 State 或其他运行替最终报告补分；
5. 不覆盖任何 v2.0 历史评分证据。
