## 1. 业务边界

- 报告评分智能体只评价已经生成的攻击溯源报告，不参与攻击执行、Wazuh 告警采集或溯源报告生成。
- 当前评分标准固定为 `v3.0`，总分 100 分，六个正式维度名称为初始事件识别准确性、关键证据检索与覆盖度、事件时间线准确性、攻击链重建与因果分析、MITRE ATT&CK 映射质量和未发生行为核验；同时保留优点、缺点、根因归纳和未发生行为规则。
- DeepSeek 是当前评分模型提供方；评分结果属于“评分智能体的模型评审结果”，不是人工分数，也不是被评分智能体自己的自评分。
- 当前目标是先保证 LangGraph Studio 和项目完整前后端两条调用链稳定可用。模型分数与人工分数的校准不属于本小阶段验收条件。

## 2. 已实现能力

- LangGraph 已注册 `report_scoring_agent`，支持在 Studio 中提交 Human Input 并查看最终状态、AIMessage 和结构化分数。
- 后端提供报告登记、Studio 导入、报告列表、评分/重评分、评分历史、最新分数、分数详情和多智能体对比接口。
- 报告、评分 attempt 和最终结果使用文件持久化，并具有请求幂等、重评分和失败状态记录。
- 模型输出经过结构化解析、字段校验、分数重算和负向行为规则处理后才持久化。
- 前端评分入口受 `VITE_ENABLE_REPORT_SCORING=true` 控制，可完成报告登记、发起评分、查看六维详情、历史和对比。
- 数智运维工作台新增开发测试模块，受 `VITE_ENABLE_TEST_MODULE` 控制；正式 AI 智能助手保留仅使用路由智能体的对话窗口，测试模块可选择攻击溯源智能体和两个基线智能体，并使用独立会话存储。
- 报告评分入口已从正式 AI 智能助手迁移到测试模块；`VITE_ENABLE_REPORT_SCORING` 继续保留，用于控制测试模块中的评分功能。
- 功能导航按分组数组纵向渲染；关闭 `VITE_ENABLE_TEST_MODULE` 后“测试”分组不生成，后续分组会自动上移，不会留下固定空位。
- 已内置 SIM-204、SIM-205、SIM-206 测试用例与评分标准目录。
- 六维度稳定结构化字段保持不变；后端和前端分别通过统一映射输出相同的正式中文名称，提示词版本更新为 `report-scoring-v3.0-4`。
- 正式评分标准、设计文档、当前运行指南和运行时标准副本已同步；标准 SHA256 更新为 `58606b7a13078cbb4e95504e747596c0851771fad26c49b7d120df5cc977e7a2`。
